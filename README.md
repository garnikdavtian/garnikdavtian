## Featured Projects

### [MyConcertBot](https://github.com/garnikdavtian/MyConcertBot)
**A production-grade RAG chatbot for concert & live-music intelligence**
* **Tech Stack:** Python, LangChain, OpenAI (GPT-4o-mini), FAISS, Streamlit, SerpAPI.
* **Highlights:** * Built a robust RAG pipeline with chunk-level document retrieval via FAISS.
  * Implemented an LLM-based topic classifier to gate non-concert questions.
  * Features a multi-format document ingestion engine (PDF, TXT, DOCX) with fallback to online SerpAPI searches.
  * Abstracted architecture allowing seamless switching between OpenAI and local Ollama models.

### [Face Analyzer](https://github.com/garnikdavtian/Face-analyzer-app)
**Multi-Attribute Facial Analysis App — Age · Gender · Race · Emotion**
* **Tech Stack:** Python, Streamlit, DeepFace, OpenCV, Docker, GitHub Actions.
* **Highlights:**
  * Developed an interactive CV app that performs multi-attribute analysis from uploaded images or live video streams.
  * Exposes full confidence distributions instead of simple prediction labels for deep transparency.
  * Supports multiple detection backends (`opencv`, `retinaface`, `mtcnn`, `ssd`, `mediapipe`).
  * Fully Dockerized with a configured CI/CD pipeline for automated testing and linting.

### [House Prices: Advanced Regression Techniques](https://github.com/garnikdavtian/House_Pricing_Competitional)
**Top 5% Result on Kaggle**
* **Tech Stack:** Scikit-Learn, XGBoost, LightGBM, Pandas, NumPy.
* **Highlights:**
  * Predicted residential property sale prices using a complex **7-model stacking ensemble**.
  * Aggressive feature engineering resulting in 30+ new features (polynomials, interactions, target encoding).
  * Weighted blending of Ridge, Lasso, ElasticNet, KRR, GBR, XGBoost, and LightGBM models.
  * Achieved a highly competitive RMSLE score through rigorous EDA and cross-validation strategies.
